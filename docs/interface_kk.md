# SoundSense интерфейсі

Интерфейс ашық фон, күлгін акценттер, дөңгеленген карточкалар және қара-күлгін талдау аймағы бар бақылау тақтасы ретінде безендірілген. Негізгі мәзірден дыбыс талдауына, графиктерге және нұсқаулыққа өтуге болады. Шағын экранда карточкалар мен талдау бағандары бірінің астына бірі орналасады.

Тақырыптар, батырмалар, нәтижедегі санаттар, график осьтері және тыңдау панелінің атауы қазақша берілген. Файл жүктеу мен ойнатқыштың Gradio басқару мәтіндері де қазақшаға бейімделген. SoundSense атауы және WAV, MP3 сияқты формат белгілері сақталған.

Бұрынғы мүмкіндіктер сақталады: 16 кеңейтімді жүктеу, алғашқы бес секундты өңдеу, дыбыс санатын анықтау, үздік үш болжам ықтималдығын көрсету, толқын пішіні мен Мел-спектрограмма, өңделген аудионы тыңдау. 100 МБ шегі, модельдер және preprocessing өзгертілмеген. Ғылыми нәтижелердегі бастапқы ағылшынша санат белгілері де өзгермейді.

```powershell
.\.venv\Scripts\python.exe app.py
```

Интерфейс коды: `app.py`, `soundsense/interface.py`, `assets/interface.css`, `assets/interface.js`.

Қызметтердің сақталуын тексеру: `python tools/check_interface.py`. Нақты нәтиже: [interface_validation.json](../results/interface_validation.json). Форматтар мен жергілікті API тексеруі: [audio_formats_validation.json](../results/audio_formats_validation.json).
