# YAMNet және EfficientNet B0 интерфейсі

Модель тізімінен YAMNet немесе EfficientNet-B0 таңдаңыз. Әдепкісі YAMNet.
Аудиофайл жүктеп «Дыбысты талдау» батырмасын басыңыз. Экранда санат, top-3 және өңделген аудио көрсетіледі.
Дыбыс көрінісі бетіне waveform және таңдалған модельдің Mel спектрограммасы беріледі.
YAMNet native log Mel, EfficientNet-B0 power-dB Mel қолданады. График атауы нақты қолданылған модельді көрсетеді.
Фондағы worker бастапқы жүктелгеннен кейін қайта қолданылады; YAMNet ортасы іске қосылмаса қолданба нақты қатемен тоқтайды.

API `/predict` аудиофайл мен модель атауын қабылдап, бес шығыс береді. Атаусыз ескі шақыру YAMNet-ті қолданады. Бір мезгілде бір талдау, кезек шегі 8.
Уақытша файлдар үшін retention 3600 с, cleanup interval 300 с. Ең үлкен жүктеу 100 МБ.
16 аудио кеңейтімі және алғашқы бес секунд ережесі сақталған. Толық орнату мен тексеру README ішінде.
